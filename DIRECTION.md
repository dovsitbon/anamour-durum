# Direction artistique — Anamour Durum (site 14)

**Angle** : la nuit à Istanbul, le grill qui fume — broches qui tournent, enseignes d'ocakbaşı, verre de çay tulipe.

## Palette
| Rôle | Hex |
|---|---|
| Noir charbon (fond dominant) | `#141110` |
| Charbon relevé (panneaux) | `#221C19` |
| Ambre / or du thé (accent principal, texte sur charbon) | `#E0A23A` |
| Rouge piment (CTA, accents rares) | `#C42A1E` |
| Crème (texte courant sur charbon) | `#F4E9D6` |

## Polices
- Titres : **Archivo Black** (`@fontsource/archivo-black`), capitales serrées, empilées.
- Texte : **Archivo** variable (`@fontsource-variable/archivo`).

## Structure de l'accueil
1. Hero sombre plein écran : « Dürüm, grillades et lahmacun, 7 jours sur 7 » en Archivo Black empilé façon enseigne lumineuse ; à droite le **verre de çay SVG** avec vapeur légère (« le thé est offert ») ; 4,6/5, Voir la carte + Appeler, statut.
2. **La borne en 3 étapes** (grands chiffres ambrés, schéma borne → table → service + thé).
3. La carte en panneaux d'enseigne (dürüm, grec, assiettes, grillades, lahmacun, sauces, accompagnements, boissons).
4. La salle, vu sur les réseaux, avis, infos.
Motif géométrique ottoman original en SVG, très discret, en filigrane des séparateurs.

## Élément signature
Le verre de çay en SVG comme marque + la borne expliquée en 3 étapes.

## Ce qui le distingue
Seul site majoritairement sombre avec accent ambre. Garage 2000 utilise du noir laqué mais sur fond blanc dominant, avec rouge vernis et Michroma large ; ici charbon chaud + ambre + grotesque très grasse.
